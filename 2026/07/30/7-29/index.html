给远程服务器的claude code任务结束设置本机提醒

  • 基本原理：远程服务器向本机建立ssh连接，然后发送notify-send指令，进而实现提醒

  • step1 本地ssh建立

# 查看 sshd 是否在运行
sudo systemctl status sshd
# 安装 SSH 服务
sudo apt install openssh-server -y

# 启动
sudo systemctl start sshd

# 设为开机自启
sudo systemctl enable sshd

# 确认已运行
sudo systemctl status sshd
  • step 2 服务器建立到本机的免密连接 以下操作是在本机执行的，本机是客户端，使用ssh 最开始在config里面进行简单配置，使得其能够始终调用同一个TCP进行消息传输
Host yourip

	ControlMaster auto
	
	ControlPath ~/.ssh/ctrl-%C
	
	ControlPersist 10m

然后通过

ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""

生成无输入私钥；然后copyid，输入秘钥后实现公钥拷贝到本机~/.ssh/authorized_keys

ssh-copy-id yourname@remoteip
  • step 3 claude code 设置hook 在远程的 ~/.claude/settings.json 中配置 hook：
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "ssh <本地用户名>@<本地机器IP> \"notify-send 'Claude Code' '任务已完成'\""
          }
        ]
      }
    ],
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "ssh <本地用户名>@<本地机器IP> \"notify-send -u critical 'Claude Code' '需要你的输入'\""
          }
        ]
      }
    ]
  }
}

当然，可以进一步编写更复杂的脚本，例如提取当前完成任务的session_id，以及其首句对话等来提高对话辨识度。
